## Описание проекта

Данный репозиторий создан в рамках выполнения **Практической работы №10**. Проект представляет собой консольное приложение на платформе .NET с настроенной интеграцией системы контроля версий.

**Реализованный функционал:**
1.  Создание локального и удаленного репозитория.
2.  *Вывод текущей даты и времени* (Задание 1).
3.  Настройка автоматизации через GitHub Actions.

### Требования к окружению (System Requirements)

Для корректного запуска приложения необходимы следующие компоненты:

*   **Платформа**: [.NET SDK 6.0 или выше](https://dotnet.microsoft.com/ru-ru/download).
*   **ОС**: Windows / Linux / macOS.

## Инструкция по развертыванию

1.  **Клонирование репозитория:**
    ```bash
    git clone https://github.com/parsifal-cxx/GIT_PR10_Bubnov.git
    ```

2.  **Запуск приложения:**
    Выполните команду в корневой директории проекта:
    ```bash
    dotnet run
    ```
